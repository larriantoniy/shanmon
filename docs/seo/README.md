# SEO journal

Журнал фиксирует управляемые SEO-эксперименты для `shanmon74.ru`.

Процесс каждого эксперимента:

1. **Before** — зафиксировать исходные данные и период измерения.
2. **Hypothesis** — сформулировать проверяемую гипотезу без прогноза неподтверждённых результатов.
3. **Change** — записать минимальное внесённое изменение и версию deploy.
4. **After** — повторить те же измерения после достаточного периода и переобхода.
5. **Learning** — зафиксировать вывод только из сопоставимых данных.

> Нет SEO-изменения без зафиксированного Before -> Hypothesis -> Change -> After -> Learning.

Сначала процесс проверяется вручную на данных Яндекс Вебмастера через Seyka. Решение об автоматизации или разработке SEO Agent принимается отдельно, только после появления повторяемого процесса и данных.
