# Manual SEO experiments

Этот каталог предназначен только для настоящих контролируемых SEO experiments.

```text
OBSERVATION
↓
EVIDENCE
↓
HYPOTHESIS
↓
BASELINE
↓
PROPOSED CHANGE
↓
HUMAN APPROVAL
↓
IMPLEMENTATION
↓
DEPLOY
↓
POST-DEPLOY VALIDATION
↓
OBSERVATION WINDOW
↓
MEASUREMENT
↓
VERDICT
↓
LEARNING
```

`SEO-EXP-001` пока не существует. Номер остаётся свободным до появления достаточных данных Яндекс Вебмастера и конкретной evidence-based opportunity.

Если данных недостаточно, допустимый вывод: `INSUFFICIENT_DATA`.

Новый experiment создаётся только после human approval и должен содержать сопоставимые baseline, гипотезу, изолированное изменение, период наблюдения, измерение и итоговый learning.
